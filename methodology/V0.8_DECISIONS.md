# V0.8 candidate — Arbitrages validés et périmètre

Statut : décisions de conception validées ; implémentation et tests à réaliser.
Source : arbitrages utilisateur du 15 novembre 2026 après audit Claude #66.
La V0.7 reste la référence antérieure ; aucune migration automatique des workspaces existants.

## Architecture et initialisation
- Un développeur dispose d'un dépôt GitHub privé unique pour toutes ses solutions.
- Un projet ChatGPT = une solution fonctionnelle Power Platform = un workspace sous `workspaces/<projectId>/`.
- Les standards et modèles communs résident dans `methodology/`.
- Ne pas prévoir de migration vers un dépôt par solution.
- Parcours cible : (1) créer le projet ChatGPT, (2) coller les instructions communes, (3) ajouter les documents métier, (4) fournir le nom ou identifiant de solution, (5) confirmer l'initialisation.
- L'assistant propose et, après autorisation et vérification des outils, crée ou réutilise le workspace et ses fichiers de configuration ; aucun YAML de configuration manuel imposé au développeur.

## D1 — Mémoire
- L0 : état global, décisions, version méthodologique, index des composants.
- L1 : état et contexte ciblés par composant, dépendances.
- L2 : historique détaillé, incidents, tests et preuves du composant.
- Aligner manifeste et index ; charger progressivement L0 puis composants nécessaires.

## D2 — GitHub
- Dépôt privé unique par développeur, workspaces distincts par solution ; pas de cloisonnement d'accès entre les workspaces du même développeur.

## D3 — Convention Power Fx
- Demander à l'initialisation la langue de l'éditeur Power Apps Studio : `fr-FR` ou `en-US`.
- Enregistrer `powerFxLocale` dans la configuration du projet ; la réutiliser dans les chats suivants ; permettre un changement explicite.
- Exemple fr-FR (éditeur) : arguments `;`, instructions `;;`, décimales `,`.
- Exemple en-US (éditeur) : arguments `,`, instructions `;`, décimales `.`.
- La syntaxe effectivement attendue dans le YAML de collage doit faire l'objet d'un test Studio distinct ; ne pas inférer sa sérialisation de la seule langue de l'éditeur.

## D4 — Canvas
- Sortie standard : YAML d'écran/contrôles destiné au collage dans Power Apps Studio.
- Fichiers `.pa.yaml` hors du périmètre standard V0.8 ; pas de connexion ou déploiement Power Platform autonome.

## D5 — Données
- Autoriser dans le workspace les artefacts et traces techniques non sensibles.
- Ne pas copier automatiquement les documents métier ou informations confidentielles depuis les sources ChatGPT.
- Ne jamais publier de secrets, clés API, jetons ou mots de passe.
- Écrire dans le workspace concerné ; demander autorisation pour les décisions structurantes et les modifications hors périmètre.
- Pas de mécanisme lourd de sécurité imposé à un dépôt personnel privé ; respecter les politiques de l'organisation.

## D6 — Outillage
- Méthodologie commune autonome avec ChatGPT et GitHub.
- Aucune référence ni dépendance au Bridge ou à Claude Code dans les instructions ou standards partagés.
- Les capacités personnelles éventuelles du développeur restent extérieures à la méthode.

## D7 — Recette
- Recette standard pour nouvelles fonctionnalités, écrans et changements métier significatifs.
- Recette allégée pour corrections mineures, avec vérifications ciblées et confirmation du développeur.
- Aucune validation automatique sur la seule base d'une auto-relecture du modèle.

## Santé du contexte
- Diagnostic « Audit contexte » sur continuité, cohérence, traçabilité et capacité de reprise.
- Alerte proactive lorsqu'un risque de dérive apparaît ; passation structurée lors d'un changement de chat.
- Ne jamais prétendre mesurer précisément l'occupation de la fenêtre de contexte ni garantir la détection d'informations tronquées.

## Points à vérifier avant publication
- Tester le YAML de collage et les séparateurs dans Studio fr-FR et en-US.
- Vérifier l'initialisation complète sur un projet neuf et la réutilisation d'un workspace existant.
- Vérifier la cohérence entre instructions, standards, manifestes et configuration.
- Ne pas promouvoir la candidate sur `main` sans validation explicite.
